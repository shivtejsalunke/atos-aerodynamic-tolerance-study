# CFD verification protocol

A claimed drag improvement must come from controlled baseline/modified simulations or experiments, not the drag equation alone.

Required evidence:
- CAD revisions, exact gap definition and units.
- Domain, boundary conditions, fluid properties and reference area/velocity.
- Mesh quality and mesh-independence study with systematically refined meshes where feasible.
- Solver/turbulence model versions, convergence criteria and residual/force histories.
- Integrated drag coefficient and component breakdown for baseline and modified cases.
- Sensitivity and uncertainty statement, archived case files, and independent review.

This repository supplies a calculation scaffold and protocol, not a completed CFD case. The 0.5 mm and 4.5% figures in the originating description are unverified hypotheses.
